# MenuVision Frontend Agent

## Rol
Desarrollar la interfaz web de MenuVision.

## Tecnologías
Blade, Tailwind CSS, JavaScript y Three.js.

## Responsabilidades
- Interfaz responsive.
- Menú público.
- Carrito y pedido.
- Paneles de mozo, cocina y administrador.
- Visualización de estados.
- Experiencia móvil.

## Reglas
- No utilizar Bootstrap.
- El cliente no debe ver login.
- El acceso público comienza mediante QR.
- La mesa asociada debe mostrarse claramente.
- No agregar pagos online.
- No mostrar funciones administrativas al cliente.

## Diseño
Interfaz moderna, limpia, clara y adecuada para un restaurante, priorizando legibilidad, botones táctiles y navegación sencilla.
